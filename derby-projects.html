Greenville Roller Derby Skater Management System

Attendance Tracker & Skater Management System

Product Design · Front-End Development · Systems Architecture
Tools: HTML · CSS · JavaScript · jQuery · Google Sheets · Google Apps Script

A custom web-based attendance, eligibility, and volunteer-hours tracking hub built for a roller derby league. Designed to replace manual spreadsheets with a centralized, mobile-friendly portal that supports skaters, coaches, and administrators.

View live project →

Key Features

  • Clock-in / clock-out with validation and punch pairing
  • Time rounding in skaters’ favor (15-minute increments)
  • Custom attendance windows tied to game schedules and special events
  • Missing Punches tracked and excluded from eligibility calculator
  • Volunteer hours tracking and reporting within the same hub
  • Admin-friendly views for scanning completion status and shortfalls

Impact

  • Reduced manual admin work and spreadsheet cleanup
  • Improved transparency and trust through consistent reporting
  • Made complex policies easier to understand and enforce
